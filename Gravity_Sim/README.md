# N Body Simulation

Simulates a solar system where the user can spawn planets, they gain their orbits and revolve around the sun. It also has a rocket which can navigate through arrow keys

## Physics
- Newton's Gravity: F= GM1M2/r²
- Orbital velocity: v = √(GM/r)
- Uses momentum to prevent collapsing into the sun

## Built With
- C++
- SFML
